On-Site IT and Network Engineering for Architecture Firms

Design studios run on heavy hardware: powerful workstations, large file servers, plotters, and networks that move huge project files all day. DTCloudOn sends technicians on-site to architecture firms in all 50 states to install and build out that equipment, then supports it remotely once it is in place.

  • CAD and BIM workstation deployment. Setup and configuration of high-performance workstations, monitors and peripherals for AutoCAD, Revit, Rhino, SketchUp and rendering software.
  • High-speed office network installation. Switches, routers and firewalls sized for large CAD, BIM and rendering files.
  • File server and NAS installation. Centralized storage for project files and Revit central models.
  • Plotter and wide-format printer setup. Installation, network configuration and driver setup for plotters, wide-format printers and large-format scanners.
  • Structured network cabling. Ethernet cabling and network drops for workstations, plotters and studio equipment, installed, labeled and tested.
  • Wireless network design and installation. Site surveys and Wi-Fi access points for open studios, conference rooms and client presentation spaces.
  • Conference room and video conferencing setup. Displays, cameras and video conferencing systems for client presentations and design reviews.
  • Server room and network rack build-outs. Rack installation, cable management, UPS battery backup and power for server rooms and network closets.
  • Access control systems. Badge readers and door access control to keep studios and plan rooms secure.
  • Security camera installation. IP security cameras and video recording systems for your office.
  • Office moves and IT relocations. Planning, disconnection and reinstallation of IT equipment when your studio moves or expands.
  • On-site troubleshooting and hardware repair. Technician visits for workstation, network and printer problems that cannot be fixed remotely.
